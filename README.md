# IIT-02 — IIT Super-50 Native Android

This repository is the native Android rebuild of IIT Super-50.

## Stack
- React Native
- Expo SDK 57
- Expo Router
- TypeScript
- Firebase integration planned
- Android APK/AAB builds through GitHub Actions

This is intentionally NOT a Capacitor/PWA wrapper. The UI is implemented with React Native components and runs through the native Android runtime.

## Migration
The original IIT web/PWA repository remains separate. Features are being migrated module-by-module into this native project.
